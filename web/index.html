Project Synopsis

Saarthi AI (सारथी) is an end-to-end multimodal voice assistant built with a Bidirectional LSTM (Bi-LSTM) deep neural network. It classifies natural language user queries into 29 intent classes, extracting query parameters to trigger modular system, web, calculation, and productivity skills.

Key Engineering Advantages

  • Offline Privacy: Intent classification and TTS run 100% locally on the client machine.
  • Sub-20ms Latency: Highly optimized Bi-LSTM architecture executes without latency lags.
  • Safe AST Parser: Eliminates dangerous eval() code execution vulnerabilities.
  • Dual Multimodal Input: Supports both browser Web Speech API microphone input and keyboard text input.
